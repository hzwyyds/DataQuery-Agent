# Upstream Attribution

DataQuery Agent is a substantial, independently maintained refactor derived
from the open-source `shopkeeper-agent` project:

- Upstream: https://github.com/didilili/shopkeeper-agent
- Reference revision: `8045fa4d61608f58df551fda6cd1a70529bb5b67`
- Upstream license: MIT

The original copyright and license are preserved in `LICENSE`.

This repository replaces the upstream metadata stack and query workflow with
a local-first architecture built around SQLite, DuckDB, workspace-scoped RAG,
structured planning, grounded result synthesis, and a new React workbench.
